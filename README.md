# NurApps Site

Каталог приложений с открытым исходным кодом от NurApps.

## Технологии

- Next.js 15 (App Router, Static Export)
- TypeScript
- Tailwind CSS v4
- Lucide React (иконки)

## Возможности

- Каталог приложений с фильтрацией по платформам
- Детальные модальные окна с версиями и скачиванием
- Мультиязычность (RU / ENG)
- Три темы (светлая, тёмная, системная)
- FAQ секция
- Новости
- О нас
- Статистика приложений
- Поиск по приложениям
- Кнопка "наверх"
- Telegram рассылка

## Запуск

```bash
npm install
npm run dev
```

## Деплой

Проект экспортируется как статика (`output: "export"`), готов для Cloudflare Pages / Vercel / любого хостинга.

```bash
npm run build
```

Папка `out/` готова к деплою.
